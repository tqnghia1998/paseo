# Palette literals (theme sites)

The Space App Vibing palette is exactly **13 colours per mode** (26 literal values). Every surface of an embedded Paseo
frame derives from them by ONE role mapping that is identical in light and dark; a mode changes only the values.

| Role | Dark | Light |
| --- | --- | --- |
| `canvas` | `#1d2125` | `#d6d8df` |
| `raised` | `#24292e` | `#e6e7ed` |
| `hover` | `#2f363d` | `#cbcdd3` |
| `selected` | `#444d56` | `#c6c9cf` |
| `faint` | `#959da5` | `#686a77` |
| `subdued` | `#d1d5da` | `#4c505e` |
| `text` | `#f6f8fa` | `#343b59` |
| `border` | `#2b3137` | `#c1c2c7` |
| `blue` | `#79b8ff` | `#395d99` |
| `green` | `#28a745` | `#33635c` |
| `yellow` | `#f9c513` | `#7e5211` |
| `red` | `#f97583` | `#8c4351` |
| `purple` | `#b392f0` | `#7540b1` |

Roles: `canvas` = neutral-850, `raised` = neutral-800, `hover` = neutral-750, `selected` = neutral-700, `faint` /
`subdued` / `text` = neutral-400 / 300 / 200, `border`, and the `blue`, `green`, `yellow`, `red`, `purple` hues. They equal
the `--palette-*` primitives in Space App Vibing's `src/index.css` (docs/theme.md).

This file lists every file and line in the fork where one of those 26 hexes is written as a literal, and the role it
plays, so a hex-substitution script can rewrite old to new primitive values in exactly these places. It was generated
from a scan (case-insensitive) of the tracked and untracked files of this repository, excluding generated `*.gen.*`
bundles and `package-lock.json`. `packages/app/src/patches/vibing/palette.test.ts` keeps the guarantees that make the
list complete:

- `palette.ts` and `plugins/space-app-vibing-theme/index.client.ts` each contain all 26 primitives as literals;
- no other hex literal except `#ffffff` (the pole mixes go toward, in both modes) appears in code (comments excluded) in
  `palette.ts`, `chief-theme.ts`, `default-dark-tint.ts` or the theme plugin;
- the plugin's per-mode colours equal `pluginThemeColors(VIBING_PALETTES[mode])`, so the two literal tables cannot drift.

Everything else is derived from those literals at run time: the default tints (`default-dark-tint.ts`), Chief's
`CHIEF_PALETTES` (`chief-theme.ts`, `accentBright` is the accent mixed 15% toward white) and the Bots plugin's
`nativeTokens` mixes (`scripts/paseo-bots-vibing.patch`, regenerate with `node scripts/vendor-community-plugins.mjs
paseo-bots`). No palette-like hex literal exists in any of them.

## A. Source of truth (rewrite these)

| File | What it holds |
| --- | --- |
| `packages/app/src/patches/vibing/palette.ts` | `VIBING_PALETTES`: the app's copy (default tints, Chief palette). |
| `plugins/space-app-vibing-theme/index.client.ts` | `PALETTES`: the theme plugin's copy (a plugin cannot import app source). Bundled copy: `scripts/paseo-web/builtin-plugins/space-app-vibing-theme/` in Vibing is regenerated by the bundle build. |
| `packages/app/public/index.html` | Pre-React background while the OS prefers dark: dark `canvas`. There is no light equivalent (a light OS shows the default white page until the frame mounts). |
